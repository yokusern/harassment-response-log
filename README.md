# カスハラ対応記録・証跡システム（デモ）

EC・小売・コールセンター向けのカスタマーハラスメント（カスハラ）対応記録・証跡管理システムのデモです。
架空の小売チェーン「くらし雑貨 ほのぼのマート」を舞台に、ハラスメント対応の記録・共有・エスカレーションを一元管理する想定で作っています。

## 背景

カスタマーハラスメント対策は全事業者向けに義務化の方向が報じられており、電話だけでなくメール・チャット・SNSでのハラスメントも対象になります。
中小事業者では「記録が残らない」「証跡がない」「対応が属人化する」という課題が想定され、本デモはその解決イメージを示すものです。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要、外部依存なし、単一ファイル）。

- データはブラウザの localStorage に保存されます（外部送信なし）
- 初回はサンプル記録5件（すべて架空）が表示されます
- 「サンプルデータに戻す」ボタンでいつでも初期状態に戻せます

## 実装機能

- **対応記録の登録フォーム**: 日時／チャネル（電話・メール・チャット・SNS・対面）／相手区分（顧客・取引先・不明）／分類（暴言・脅迫、過剰な要求、長時間拘束、SNS晒し予告、セクハラ、その他）／深刻度（低・中・高・緊急）／対応者／内容メモ／対応経過メモ
- **一覧・検索・フィルタ**: キーワード検索、チャネル別・深刻度別・ステータス（未対応／対応中／完了）フィルタ
- **証跡タイムライン**: 各記録について「登録 → 一次対応 → 上長共有 → 外部連携 → 完了」の経過を時系列で表示。経過の追加とステータス変更も可能
- **エスカレーション手順チェックリスト**: 深刻度ごとに異なる対応フローを表示し、チェック状態を保存
- **対応テンプレート文例**: 線引き・長時間拘束の切り替え・暴言への警告・SNS晒し予告への対応・エスカレーション連絡の5種。ワンクリックでコピー可能
- **統計ダッシュボード**: 総件数・未完了件数・深刻度別の集計サマリと、分類別・深刻度別・チャネル別の件数バー表示
- **CSVエクスポート**: 全記録をExcelで開ける形式（BOM付きUTF-8）でダウンロード
- **印刷用レポート**: 印刷専用レイアウトで一覧表を出力
- セマンティックHTML、モバイル対応レスポンシブレイアウト

## 注意

- 店舗名・記録内容はすべて架空です。実在の個人名・企業名は使用していません
- エスカレーション手順やテンプレート文例はデモ用の一般例です。実運用では自社の対応マニュアル・就業規則・法令（労働施策総合推進法等の改正動向）に沿った内容に差し替えてください
- 本デモはブラウザ内保存のため、複数端末・複数担当者での共有はできません。実運用版では認証付きのサーバー保存・アクセス権管理が必要です
